# E-Commerce Sales & Operations Analysis — Excel

## Project Overview

This project analyzes e-commerce sales, profitability, customer behavior, order status, and delivery performance using Microsoft Excel.

The objective is to transform raw sales data into meaningful business insights and present the results through an interactive Excel dashboard.

## Business Objectives

- Analyze overall sales and profitability.
- Identify high-performing categories, products, and regions.
- Understand order status and return patterns.
- Analyze delivery performance.
- Compare new and returning customers.
- Build an interactive dashboard using PivotTables, PivotCharts, and Slicers.

## Key Business Insights

- Electronics generated the highest sales among the analyzed categories.
- Stationery ranked as the most profitable category after comparing category profitability.
- Laptop was the strongest product based on Net Sales, while Monitor performed strongly based on Profit Margin.
- West was the top-performing region based on the analyzed sales performance.
- Delivery performance can be monitored using delivery categories and average delivery days to identify opportunities for improvement.
- Customer and order analysis can help businesses understand purchasing behavior, returns, and opportunities to improve customer retention.
